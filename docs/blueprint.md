# **App Name**: Lanka Bus Ticket

## Core Features:

- Route Selection: Users can select a start and end point from a predefined list of locations in Sri Lanka.
- Bus and Seat Selection: Display available buses for the selected route, allow seat selection, and simulate a payment confirmation.
- QR Code Ticket Generation: Generate a QR code containing route, bus, and 'payment' details, with a download option.

## Style Guidelines:

- Primary color: Teal (#008080) to evoke a sense of travel and reliability.
- Secondary color: Light gray (#F0F0F0) for backgrounds and content separation.
- Accent: Yellow (#FFC107) to highlight interactive elements and call-to-actions.
- Clean and straightforward layout with clear sections for route selection, bus options, and payment simulation.
- Use recognizable icons for bus stops, seat selection, and QR code.
- Subtle transitions and animations for a smooth user experience when navigating between steps (route selection, bus selection, etc.).
